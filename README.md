# حلقة القرآن الكريم — تطبيق PWA

## الملفات
- `index.html` — التطبيق الرئيسي
- `manifest.json` — إعدادات التطبيق
- `sw.js` — Service Worker (يعمل بدون إنترنت)
- `icon-192.png` / `icon-512.png` — أيقونة التطبيق

## رفع التطبيق على GitHub Pages (مجاناً)

1. افتح https://github.com وسجّل دخول (أو أنشئ حساباً مجانياً)
2. اضغط "New repository" واسمه مثلاً: halaqah
3. اختر "Public" ثم "Create repository"
4. ارفع الملفات الأربعة (index.html, manifest.json, sw.js, icon-192.png, icon-512.png)
   - اضغط "uploading an existing file"
   - اسحب الملفات أو اختَرها
   - اضغط "Commit changes"
5. اذهب إلى Settings > Pages
6. تحت "Source" اختر "Deploy from a branch" ثم "main" ثم "/ (root)"
7. اضغط Save

رابطك سيكون: https://اسم-المستخدم.github.io/halaqah

## تثبيت التطبيق على الجوال

### Android:
- افتح الرابط في Chrome
- ستظهر رسالة "إضافة إلى الشاشة الرئيسية" — اضغطها
- أو: القائمة ⋮ > "إضافة إلى الشاشة الرئيسية"

### iPhone:
- افتح الرابط في Safari
- اضغط زر المشاركة 📤
- اختر "إضافة إلى الشاشة الرئيسية"
